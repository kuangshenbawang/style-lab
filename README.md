# STYLE LAB - AI 穿搭灵感实验室

> Vibe Coding x Fashion - AI 驱动的时尚穿搭工具集

## 功能模块

| 模块 | 功能 |
|------|------|
| 风格匹配器 | 心情 x 场合 x 季节 三步选择, 36种穿搭风格原型 |
| 色彩实验室 | HSL 色彩算法, 4种配色方案 (互补/邻近/三角/同色系) |
| OOTD文案工坊 | 4平台 x 7风格模板, 一键生成社交媒体穿搭文案 |
| 趋势风向标 | 6个2026热门趋势 (Quiet Luxury / Gorpcore / Y2K等) |

## 技术栈

- 纯前端: HTML + CSS + JavaScript (零依赖)
- 字体: Playfair Display + Noto Sans SC
- 响应式设计, 支持移动端

直接用浏览器打开 index.html, 或启动本地服务器:

